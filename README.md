# Nearby Signal Detector

Version 0.3 development package.

- `NearbySignalDetector.swiftpm/` — native SwiftUI/CoreBluetooth source.
- Radar-style signal-strength view with trend indicators.
- Baseline/new-device detection with confirmed strong-signal alerts.
- `.github/workflows/ios-ci.yml` — unsigned iOS Simulator compile check on a GitHub macOS runner.

See `NearbySignalDetector.swiftpm/README.md` for details and limitations.
