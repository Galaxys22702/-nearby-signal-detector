# Security

## Reporting a vulnerability

Please do not disclose credentials, private keys, signing material, or exploitable details in public issues.

Open a private GitHub security report when available. If private reporting is unavailable, contact the repository owner privately before publishing details.

## Sensitive material

Never commit Apple signing certificates, provisioning profiles, App Store Connect API keys, private keys, passwords, recovery codes, device identifiers, or personal data.

The project is a development and research app; BLE identifiers and signal observations should be treated as potentially sensitive data.
